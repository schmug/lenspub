    How blocks are judged

    Blocks are scored a few at a time, the ones on screen first, and zapped as each answer arrives. Set this to llama-server's --parallel value (1 scores one block at a time).

    Only addresses on this machine (localhost, 127.0.0.1) are accepted, so page text never leaves your device. Decision models (recommended) run in llama.cpp's llama-server, for example llama-server -hf ggml-org/Kev-4B-GGUF --port 8080 (Clef-flash needs a llama.cpp build with its draft support; see the README); leave Model empty unless the server hosts several. Ollama cannot serve decision models; for a chat model in Ollama, start it with OLLAMA_ORIGINS=chrome-extension://*.
